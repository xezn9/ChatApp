# المكالمات الصوتية (مجانية)

المكالمات تشتغل بـ WebRTC (الصوت مباشرة بين الجهازين)، والإشارة عبر Realtime Database،
والرنين عبر نفس الـ Worker حق الإشعارات (FCM). لازم تكون سويت خطوات `README.md` (الـ Worker و `PUSH_URL`) حتى يرن الجهاز وهو مطفي.

## 1) انشر قواعد Firebase (فيها `calls` و `incomingCalls`)
    firebase deploy --only database

## 2) حدّث الـ Worker
افتح الـ Worker بـ Cloudflare → Edit code → الصق `worker.js` الجديد → Deploy.

## 3) TURN (مهم لبعض الشبكات)
STUN من Google مجاني ويكفي لأغلب المكالمات. إذا الطرفين على إنترنت موبايل (أو شبكات مقيّدة) ممكن بعض المكالمات ما تتصل بدون TURN.
خيار مجاني: Open Relay من Metered (تسجيل بإيميل، تحقق من شروطهم الحالية):
1. سجّل بـ https://www.metered.ca/tools/openrelay/ وخذ رابط الـ credentials API.
2. حطه بـ `CallConfig.kt`:

       const val TURN_API_URL = "https://اسمك.metered.live/api/v1/turn/credentials?apiKey=XXXX"

(أو بيانات ثابتة بـ `TURN_URLS` / `TURN_USER` / `TURN_PASS`). بدون TURN يشتغل بس ممكن يفشل بحالات.

## 4) الاستخدام
بالمحادثة الفردية: زر 📞 بالشريط العلوي. المستلم يطلعله رنين بشاشة كاملة (حتى مع قفل الشاشة) فيه رد / رفض.

## ملاحظات
- أندرويد 14+: صلاحية «الإشعارات بملء الشاشة» ممكن تحتاج تفعيلها يدوياً من إعدادات التطبيق، وإلا يطلع إشعار عادي منبثق بزر رد/رفض.
- المكالمات صوتية بدون كاميرا.

## مكالمات المجموعات
- زر 📞 بالشريط العلوي للمجموعة: يبدأ مكالمة جماعية (أو ينضم إذا فيه وحدة شغالة، ويصير الزر أخضر).
- أعضاء المجموعة يوصلهم رنين بزر «انضمام» (يحتاج تحديث الـ Worker ونشر القواعد، نفس خطوات 1 و 2 فوق).
- كل مشارك يتصل مباشرة بالباقين (mesh)، فالحد الأقصى 8 مشاركين. TURN مهم أكثر هنا.
- لازم تنشر `database.rules.json` الجديد (فيه `groupCalls`) و `worker.js` الجديد (فيه `gcall`).
- الاستماع الاحتياطي: إذا خدمة الخلفية شغالة، تسمع أيضاً لـ `incomingCalls/<uid>` وترن حتى لو FCM تأخر.

## واجهة Liquid Glass + المكالمة الفائتة
- شاشات المكالمات (`CallActivity` / `GroupCallActivity`) صارت زجاجية بمكتبة Backdrop، والمكونات المشتركة بـ `CallGlass.kt`.
- المكالمة الفائتة تنكتب بالمحادثة كرسالة نص بصيغة `[[call:missed]]` / `[[call:declined]]` / `[[call:gmissed]]` (نفس فكرة الملصقات)
  فما تحتاج أي تعديل بقواعد قاعدة البيانات ولا بالـ Worker. الكرت يطلع بالمحادثة الفردية والجماعية (`ui/CallLogUi.kt`).
- الفردية: المتصل هو الي يكتب السجل إذا المستلم ما رد / رفض / مشغول / المتصل لغى قبل الرد.
- الجماعية: الي بدأ المكالمة إذا طلع وما انضم أحد.
