# v2.7: رسائل صوتية (تسجيل بضغطة مطولة + استماع قبل الإرسال + حذف)
## ⚠️ لازم تنشر قواعد Realtime Database (فيها نوع `audio` وحقل `wave` جديد)
```
firebase deploy --only database
```
بدونها إرسال الرسائل الصوتية يفشل.

- **زر المايك**: يظهر بمكان زر الإرسال إذا مربع الكتابة فاضي (إذا كتبت نص يرجع زر الإرسال). ضغطة سريعة تطلع تلميح، و**ضغطة مطولة (~0.3 ثانية)** تبدأ التسجيل: الزر يكبر ويصير أحمر، ويطلع شريط فيه نقطة حمرا تنبض + الوقت + موجة حيّة. اهتزاز خفيف عند البداية.
- **ترفع إصبعك** = يوقف التسجيل (ما ينرسل تلقائياً) وينتقل لشريط المعاينة: 🗑 حذف، ▶/⏸ استماع، موجة تگدر تسحب أو تضغط عليها للقفز، والوقت. بعدها زر الإرسال الأزرق يرسله.
- **تسجيل قصير** (أقل من ~0.7 ثانية) يتجاهله ويطلع تلميح. أقصى مدة **5 دقائق** (يوقف لحاله وينتقل للمعاينة).
- **الفقاعة**: زر تشغيل/إيقاف + موجة تتلوّن وقت التشغيل + المدة. الطرف الثاني ينزّل الملف عند أول ضغطة ويتخزن بالكاش. تشغيل رسالة يوقف الي قبلها. الضغطة المطولة تفتح قائمة الخيارات (رد، تثبيت، حذف) مثل بقية الرسائل. التعديل غير متاح للصوتيات.
- **التخزين**: نفس نظام الصور والفيديو (RTDB مقسّم base64، مسار `media/<chatId>/<id>`) بصيغة AAC/m4a مونو 16kHz بـ32kbps، يعني الدقيقة حوالي 240 كيلوبايت. حذف للجميع يمسح الملف من السيرفر.
- **الصلاحية**: أول مرة يطلب صلاحية المايك (`RECORD_AUDIO`)، بعد ما توافق اضغط مطولاً مرة ثانية.
- لو الإرسال فشل (النت) التسجيل يبقى بالمعاينة وتگدر تعيد المحاولة. إذا طلعت من المحادثة وهو بالمعاينة ينحذف.
- ملفات جديدة: `VoiceUtil.kt` (المسجّل والمشغّل) و `VoiceUi.kt` (الواجهات). رفعت `versionCode` إلى 18 و`versionName` إلى 2.7.

## 2) الضغطة المطولة على الرسالة (قائمة Liquid Glass)
- **رد** (الرسالتين)، **تثبيت / إلغاء التثبيت** (الرسالتين)، **تعديل** و**حذف** (رسائلك أنت فقط).

## 4) الأنيميشنات

- التنقل بين Home / BDF / Account: انزلاق أفقي حسب الاتجاه.
- دخول المحادثة والبروفايل: انزلاق من الجانب، والشريط السفلي ينزل ويرجع.

- تعديل / حذف / تثبيت الرسالة: نبضة على الفقاعة + تلاشي النص + ظهور دبوس التثبيت بحركة.

أندرويد يرفض التحديث إذا النسخة الجديدة موقّعة بمفتاح غير الي بالقديمة، وهذا سبب أنك كنت تحذف وتعيد التنزيل
(كل بناء بمفتاح debug مختلف يطلع بتوقيع مختلف). هسه كل نسخة (debug أو release، من أي جهاز) تنوقّع بنفس المفتاح.
⚠️ النسخة الي عندك هسه ممكن تكون بمفتاح ثاني، فالمرة الجاية بس تحتاج تحذفها وتنزل v1.3. بعدها كل التحديثات تنزل فوقها.
⚠️ احفظ `chatapp.jks` بمكان آمن ولا تغيّره أبداً.

**2) كيف تنشر تحديث:**
1. ارفع `versionCode` (رقم أكبر) و`versionName` بـ `app/build.gradle.kts` وابنِ APK (`./gradlew assembleRelease`، الملف بـ `app/build/outputs/apk/release/`).
2. ارفع الـ APK لمكان فيه رابط تنزيل مباشر `https://` (مثلاً GitHub Release لمستودع عام: `https://github.com/USER/REPO/releases/download/v1.3/app-release.apk`).
3. Firebase Console ← Firestore ← مجموعة `app_config` ← مستند `android` فيه الحقول:
   - `versionCode` (number) مثل 4
   - `versionName` (string) مثل 1.3
   - `apkUrl` (string) رابط التنزيل المباشر
   - `notes` (string) وصف التحديث (اختياري)
   - `force` (boolean) إذا true ما يگدر المستخدم يتجاوز التحديث (اختياري)
4. أي مستخدم يفتح التطبيق وفيه نسخة أقدم تطلع له شاشة تحديث، يضغط «تحديث الآن» والتطبيق ينزّل ويفتح المثبّت ويتحدّث فوق القديم.

**3) انشر القواعد:** `firebase deploy --only firestore:rules` (أضفت `app_config` للقراءة العامة).

التطبيق يتأكد قبل التثبيت أن الملف نفس التطبيق، وأحدث، ونفس التوقيع، وإذا لا يعرض سبب واضح بدل ما يفشل التثبيت.
أول مرة يطلب أندرويد صلاحية «تثبيت التطبيقات من هذا المصدر»، تفعّلها مرة وحدة.

# التعديلات الجديدة

## 1) داخل التطبيق (Kotlin) — تشتغل مباشرة بعد البناء
- صورة الملف الشخصي بجانب الرسالة (للطرفين)، مرة وحدة بآخر رسالة بالمجموعة. إذا مر دقيقتين أو أكثر تُعتبر رسالة جديدة وتظهر الصورة.
- وقت الإرسال يظهر عند أول رسالة، وبعد غياب 5 دقائق أو أكثر يظهر وقت جديد.
- زر الإعدادات ⚙ داخل المحادثة: خلفية المحادثة (5 خلفيات + المعرض + ضبابية)، فقاعات الرسائل (10 أشكال)، تثبيت، حظر، إبلاغ.
- الخلفية لكل محادثة وتنحفظ على جهازك. شكل الفقاعات يتخزن بملفك الشخصي ويطبق على كل المحادثات ويشوفه الطرف الثاني.
- المثبتين يظهرون بأعلى قائمة المحادثات مع ⭐.
- الحظر: المحظور ما يگدر يراسلك ولا يشوف ملفك (مفروض من firestore.rules مو بس من الواجهة).
- شاشة "حسابك محظور" تظهر للمعاقب وتختفي تلقائياً بعد انتهاء المدة.

## 2) لازم تنشره على Firebase (مرة وحدة)
الإشعارات وفحص البلاغات يحتاجون سيرفر (Cloud Functions)، وهذا يتطلب خطة Blaze (تدفع حسب الاستخدام، وفيه حصة مجانية).

```
npm install -g firebase-tools
firebase login
firebase use <مشروعك>
cd functions && npm install && cd ..
firebase deploy --only firestore:rules,functions
```

## 3) كيف تشتغل العقوبات
1. المستخدم يبلغ → يُحفظ البلاغ مع معرّفات آخر 15 رسالة للمبلّغ عنه.
2. السيرفر يقرأ الرسائل الحقيقية بنفسه (مو من كلام المبلّغ) ويفحصها بقوائم الكلمات في `functions/words.js`.
3. إذا ثبتت مخالفة: حظر يوم → 3 أيام → أسبوع → 14 → 28 → 56 ... (حد أقصى سنة).
4. إذا ما ثبتت تلقائياً يبقى البلاغ `pending_review` بمجموعة reports، وإذا غيّرت `status` إلى `confirmed` من Firebase Console تنطبق العقوبة.
5. كلام الشخص عن نفسه (مثل "اريد انتحر") ما ينعاقب تلقائياً، يروح `review_wellbeing` للمراجعة.
- وسّع القوائم بـ `words.js` حسب اللهجة.

## 4) الإشعارات
- توصل فقط إذا مسجل دخول: التوكن ينحذف عند الخروج.
- ما تظهر والتطبيق مفتوح. فيها اسم المرسل وصورته ونص الرسالة، والضغط عليها يفتح المحادثة.
- بدون إنترنت: الإشعار ينتظر دقيقتين فقط ثم يسقط (`ttl` بـ functions/index.js).
